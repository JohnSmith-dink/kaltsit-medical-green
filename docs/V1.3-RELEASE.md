# v1.3.0 发布依据

本版新增可选本地动态壁纸，依据为已在 NixOS generation 56 验收的源码 `7c175b88a265487c337e1dcabcb6216531b70f18`。
正式版统一主题与扩展版本为 1.3.0，更新使用文档与发布资料；播放器 QML、设置页、原版锁屏、D1 资源和恢复逻辑不再调整。

## 功能与安装范围

`kaltsit-motion` 提供静音循环、右键暂停/继续、裁切/完整显示、视频错误静态回退及恢复。
扩展单独安装和选择，默认主题包保持原有静态行为；不提供启动过渡。
公开源码和发行包不含原视频、转码视频、私人桌面截图、系统配置或恢复记录。用户自行选择本地视频；已有静态素材的许可范围见 [CREDITS](../CREDITS.md)。

## 已完成的验收

- 已验收开发包：Plasma 6.6.6 / Qt 6.11.2，NixOS 26.05，3120×2080 / 175% 内屏。
- 用户确认「画面流畅，暂停和继续正常」；原生桌面截图检查播放、暂停与恢复通过，暂停后的壁纸像素差为 0。
- 独立 HOME、D-Bus 和 KWin 会话覆盖 1920×1080 / 100% 与 3120×2080 / 175%；播放、隐藏、循环、错误回退与恢复通过。
- 纯软件绘制后端静态回退通过，设置页原生组件独立加载通过。
- 现有 84 项测试与锁定 Nix flake check 通过；正式构建与已验收构建按文件核对，运行逻辑保持一致，版本标识单独归一化比较。
- 正式源码包按 Git 内容和 76 个符号链接核对，重复打包的 SHA-256 一致；托管 CI 以对应提交的 Actions 为准。

[最小公开验收记录](v1.3-acceptance.json)保留开发构建身份，正式发行验证另行记录。历史 v1.2 截图仅展示沿用的静态外观。
硬件解码没有确定测量；长期功耗、多屏、文件选择器交互及锁屏/电池自动暂停不在已通过范围。

## 升级与恢复

已有 v1.2 基础主题可独立安装动态壁纸扩展，无需重新 apply 全局主题。
若要升级基础主题包到 1.3.0，先在桌面设置恢复原图像壁纸，再按[升级与恢复](UPGRADE-RECOVERY.md)用旧工具 restore、安装新包并 apply；之后可重新选择动态壁纸。
CLI 与 Home Manager 模块不新增动态壁纸控制接口，不修改既有恢复格式。当前实机继续使用已验收部署；发布动作不自动切换日常系统。

English: v1.3.0 publishes the accepted optional silent video wallpaper, without a startup splash or distributed video. Playback and right-click pause/resume were accepted on the built-in display. Runtime equivalence, formal builds and release archives are checked separately; hardware decoding, long-term power and multiple displays remain outside the accepted scope.
