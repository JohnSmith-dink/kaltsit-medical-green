# v1.2 截图来源

十四张截图来自已验收开发提交 `9438a15` 的独立 KDE Plasma 6.6.6 会话。
primary 为 3120×2080 / 175% / Qt Quick RHI + Mesa software OpenGL，wide 为 1920×1080 / 100% / Qt Quick software。
图片使用当时实际构建产物，保留原始字节。1.2.0 只更改版本元数据和发布资料，没有重新拍摄这些截图。
锁屏在 native greeter testing 模式捕获，不执行密码认证；软件后端不提供与 RHI 相同的 shader 模糊。

缩略图单独存放，采用 Pillow LANCZOS、RGB PNG、fit 1000×1000，无放大。原图与缩略图 SHA-256 均见 [manifest.json](manifest.json)。
真实内屏验收独立记录在 [验收数据](../../docs/v1.2-acceptance.json)，个人桌面截图和配置备份不随源码分发。
