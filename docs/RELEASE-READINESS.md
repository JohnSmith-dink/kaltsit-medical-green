# v1.1 正式版准备

当前候选：**1.1.0-rc.1**，2026-11-01（Asia/Shanghai）。

本轮按用户反馈，优先完成锁屏与桌面观感精修。采用深灰绿原生时钟、暖白解锁控件、锁屏底部渐淡衬底、细灰绿边框和柔和阴影；继续使用原始壁纸、动态指针与既有布局。

## 候选版验证

- 68 项自动检查、Nix 锁定依赖构建和 flake check。
- 原生独立 KDE 会话：应用、重复应用、恢复、失败回滚、v1.0 / dev.2 恢复后升级和组件边界。
- 3120×2080 / 175% 与 1920×1080 / 100% 的虚拟输出检查。
- Qt Quick 软件后端及 RHI / Mesa 软件 OpenGL 两条渲染路径通过。
- 中文桌面、菜单、Dolphin、浅色终端、通知，以及原生待机/输入提示页预览。
- 可复现源码发行包、SHA256SUMS、中英文说明与素材署名。

对应结果和运行方式见 [验收记录](VALIDATION.md)，图像原件及哈希见 [预览](../previews/README.md)。
主题安装不自动应用；日常 NixOS 会话仍为已部署的 dev.2。本候选不创建正式版标签或替换现有 Release。

## 正式发布前的实屏验收

1. 在日常 175% 屏幕确认待机时钟、解锁输入框和通知的观感，并实际完成一次正常锁定/解锁。
2. 实际确认动态鼠标的点击落点与五档尺寸；若使用外接显示器，检查热插拔和跨屏表现。
3. 确认当前素材组合与版本内容后，将候选版本更新为 `1.1.0`，生成正式附件并发布。

这些人工项目没有以虚拟截图或单元测试代替。已有素材权利范围保留在 [CREDITS.md](../CREDITS.md)。
