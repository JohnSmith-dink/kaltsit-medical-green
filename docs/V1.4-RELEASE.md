# v1.4.0 发布依据

发布日期：2026-11-03（Asia/Shanghai）。基线为 v1.3.0；开发定稿为 `e834b41b538d8ca4e7ebec27faf20d3097736576`。
正式版统一基础主题、动态壁纸、SDDM、控制器和元数据版本为 1.4.0，并更新安装与发布文档。
SDDM 元数据测试不再写死旧版本号；版本格式和包内一致性继续检查，发行版本一致性由现有 `test_versions.py` 对照 CHANGELOG 验证。
登录、播放器、退出确认页生成器、原版锁屏及恢复逻辑沿用该定稿，不在发布整理中改变行为。

## 本版内容

- 独立、默认关闭的 `kaltsit-sddm` Qt 6 静态登录主题与 NixOS 模块。透明左侧登录区、72px Regular 时钟、字形左边缘对齐、分组底部操作；可读取用户提供的本地 OPPO Sans 4.0，缺失时使用系统字体。
- 退出、重启与关机确认页移除整屏遮罩，保持壁纸原亮度。文字细描边、图标局部浅色圆底与焦点提示保留；上游按钮、取消和倒计时行为不变。
- 动态壁纸默认在电池供电或收到锁定状态时暂停。手动暂停优先；错误恢复每隔 60 秒最多额外重试 3 次，暂停期间不重开视频。
- Home Manager 可独立安装动态壁纸，并声明本地视频／静帧。提供独立转码脚本与功耗测量方法；安装资源不自动选择壁纸。
- 基础主题仍沿用原版锁屏与 D1。没有启动过渡、Plymouth、引导菜单或桌面组件扩展。

SDDM 继续标为实验性可选组件。初版 VM 的完整关机／重启停在 Nix store 卸载阶段，未记录为通过；后续没有重测完整电源周期。
真实高分屏 greeter 的完整人工验收、多屏、TTY 恢复和启动菜单回滚仍未完成。动态壁纸的硬件解码、长期功耗、物理电源／锁屏联动仍未确定验收；DPMS 和完全遮挡检测尚未接入。
转码脚本的参数与路径边界已用假 ffmpeg 检查，未将其标为真实视频转码验收。

## 发行与升级

源码包由独立、干净的发布副本生成，附件为 `kaltsit-medical-green-1.4.0.tar.gz` 和 `SHA256SUMS`。
发布流程核对 Git 对象、相对符号链接、可重复归档，以及附件上传后的下载哈希。公开包不包含私人视频、OPPO 字体、主机配置或恢复记录。
SDDM VM 原图与浏览器设计参考分别保存；历史截图不重新标成正式版实机验收。

基础主题升级前按 [恢复指南](UPGRADE-RECOVERY.md)使用旧版本 restore，再安装并主动 apply 新版；动态壁纸选择仍由桌面设置管理。
SDDM 单独按 [指南](SDDM.md)启用；主题模块不启用 SDDM 服务，也不覆盖用户已有显式主题设置。所有包使用系统同一套 `pkgs`，随 Plasma 更新重建。
视频和字体由用户自行提供，原有素材及 KDE 派生 QML 的署名和许可见 [CREDITS](../CREDITS.md)。

English: v1.4.0 publishes an opt-in experimental SDDM theme, transparent logout confirmation, battery/lock-aware video pause, bounded recovery and Home Manager motion installation. Publication retains the finalized runtime code and separately verifies release versions/builds/archives. VM authentication, fake-service playback checks and software-rendered confirmation checks are distinct from physical acceptance. Video/font binaries and private host state are not distributed.
