# v1.1 正式版发布记录

正式版本：**1.1.0**，2026-11-01（Asia/Shanghai）。

rc.3 已部署至 NixOS generation 54，用户完成真实锁屏输入与解锁，确认“亮度正常，解锁正常”，
并明确授权发布 v1.1 正式版。1.1.0 仅更新版本信息和文档，运行资源与已验收的 rc.3 保持一致。

锁屏移除全部壁纸遮罩，仅对本主题将原生 Fader 的亮度、对比度与饱和度系数固定为 1。
原始 JPEG 字节以及原生模糊、认证、输入和焦点逻辑保留。Complementary 使用浅底深字。
rc.1 偏亮和 rc.2 偏暗的反馈及修订历史保留在 [版本记录](../CHANGELOG.md)。

## 已完成的发布依据

- rc.3 的 69 项自动检查、离线 Nix 构建和 flake check 通过；资源缺失时零配置写入，以及显式跳过锁屏后的应用与恢复检查通过。
- RHI（3120×2080、175%）与软件后端（1920×1080、100%）完整隔离回归通过；正式版沿用该轮十张原始预览，不宣称重新拍摄。
- NixOS generation 54 的日常物理屏幕验收通过，用户确认亮度和解锁正常；此前日常鼠标点击也已确认正常。
- rc.3 提交 `d5dfb24` 的两项托管 CI 均通过。正式版发布构建和 CI 单独执行，结果另见仓库 Actions。

源码发行包和 SHA256SUMS 对应 1.1.0；历史验证保留原版本标记。
对应结果和运行方式见 [验收记录](VALIDATION.md)，图像原件及哈希见 [预览](../previews/README.md)。
主题安装不自动应用，升级时按 README 先恢复旧版本，再应用新版本。

## 兼容性与验证范围

Nix 构建生成局部 KDE QML 差异，并原样复制匹配依赖的完整 shell。
完整资源层会参与 shell 包发现，必须使用与系统相同的 `pkgs`，随 Plasma 升级重建，避免旧资源遮盖新版本。
上游替换片段有精确匹配检查；非主题分支与上游代码逐字节对照一致，未另做实时 A/B。
生成的 KDE 派生 QML 保留 GPL-2.0-or-later 许可，原创 MIT 与素材权利边界见 [CREDITS.md](../CREDITS.md)。

五档指针已完成自动检查，尚未逐档实屏核验。本轮未接入外接显示器，因此未验证热插拔和跨屏行为。
这些是验证范围说明；当前日常屏幕的亮度、解锁与用户发布授权均已完成。
