# v1.5.0 发布依据

[English](V1.5.0-RELEASE.en.md)

日期为 2026-11-08。此版本以 `508b1fff58b8bd894c4c495e879dbb0ee5c8711a` 为发布基线，整合功能定稿 `e27bc6114a8866fe7fce51af8138bbc03d26aab1`。基础主题、动态壁纸、SDDM、控制器和发行元数据统一使用 1.5.0。

## 本版内容

- 选择医疗白绿锁屏壁纸后，待机时左上方显示时间和日期。唤醒时，首字母头像和密码框出现在同一列，继续使用 Plasma 的认证流程。
- 注销、重启和关机确认页在左栏显示时钟、倒计时与操作按钮。窗口和桌面面板由主题自带锁屏壁纸覆盖，画面保留原亮度。
- SDDM 底部按钮获得键盘焦点时，显示一深一浅两道不透明边框。此变化同时适用于正常布局和错误提示布局。

使用自定义锁屏壁纸时，确认页仍显示主题自带壁纸。这项限制适用于三个会话操作。

## 真机验收

2026-11-08，候选 `c13e1aaf64759aeadff3c10c9ad489b78f50d74a` 已按 build → boot 部署，重启后确认运行所构建的系统与 1.5.0 资源。发布整理只更新文档，运行代码与该候选相同。

负责人在单屏 Wayland、3120×2080、175% 下报告：登录页透明布局、壁纸亮度与文字正常；SDDM 首字符、错误提示及随后正确登录正常；锁屏字母唤醒保留首字、错误后立即重输及解锁正常；休眠后唤醒与解锁正常。重启确认页单次空白点击成功取消，W8 增加真机通过的结论，先前虚拟机未通过的记录保留。

上述交互是负责人实测反馈；成功启动与会话状态另有只读系统核对。没有采集真机原图或重测真机对比度；休眠时序未得到日志独立佐证。完整关机、注销流程、多屏、TTY 恢复与启动菜单回滚未在此轮重测。

本地候选共 115 项 Python 测试通过，flake check 与三个包构建通过。候选虚拟机图像对照中，首帧与聚焦帧各为 16 px／4，错误态为 32 px／7，关机焦点获准采用同条件配对的 41 px／7，锁屏唤醒为 6 px／3，29 秒确认页为 10 px／2。使用原定时钟／倒计时掩膜及 100 px／8 门槛。历史参照的首帧 1,788 px／207、旧关机焦点对照和光标相位失败保留，未作为通过结果。发布整理后的测试、构建与附件校验以仓库 Actions 和正式发行附件为准。

## 安装与升级

从 1.5.0 源码目录运行 `nix build --no-write-lock-file path:.#kaltsit-theme` 构建基础包。`kaltsit-motion` 和 `kaltsit-sddm` 分别构建与安装，SDDM 需显式启用。系统模块使用调用方的 `pkgs`。基础主题的旧恢复记录应在升级前使用原版本恢复。[安装说明](../README.md) · [恢复指南](UPGRADE-RECOVERY.md) · [SDDM](SDDM.md) · [动态壁纸](MOTION.md)

源码包名称为 `kaltsit-medical-green-1.5.0.tar.gz`。素材作者、来源与许可列于 [CREDITS](../CREDITS.md) 和 [许可目录](../LICENSES/)。
