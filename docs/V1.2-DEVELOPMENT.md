# v1.2 开发记录（未发布）

2026-11-01 · 基于 v1.1.0（`0bf00f8515a368d9dd6cbcaab54bfada088f8218`）的独立 `improve/v1.2-dev` 分支。

## 已选方向与实现

- 用户选定原版锁屏与桌面 D1。锁屏排版、字体、底部文字、亮度处理、壁纸与认证逻辑沿用 v1.1。
- D1 改四张 Plasma SVG：面板圆角 8、弹窗 10、提示框 6，阴影不透明度 0.12。既有面板高度、位置、组件、顺序不由主题改写；没有引入布局脚本。
- 新增只读版本诊断。构建版本由 Nix 写入元数据；运行版本从当前会话的 Plasma PID 对应 Nix executable 识别。缺失证据时为 unknown，不执行 PATH 中的 plasmashell 来猜测。
- 修复配置读取与编辑对换行符的处理。未被后改的非 GTK 文件恢复原始字节；有后改时继续按键恢复，GTK 保持主题键边界。CLI 命令、Home Manager 接口及恢复格式不变。
- 中英文 README 与恢复指南同步；十张旧原图分别生成有哈希来源记录的缩略图，原图不重写；开发版历史移至 HISTORY。
- 每周锁定依赖检查与 unstable 探测使用独立任务、只读权限和固定 Action SHA，不创建更新 PR。

## 对 Claude 建议的采用情况

| 处理 | 本轮结果 |
|---|---|
| 采用 | 隔离会话、保护原始素材与授权记录、原图与缩略图分离、如实区分预览与实机验收。 |
| 采用 | 版本诊断、INI/恢复边缘用例、README 整理、升级/TTY 恢复/卸载说明、每周构建检查。 |
| 调整 | 版本诊断核对当前会话进程，不把 PATH 所指新包当作运行版本；同版本只表示版本号匹配。 |
| 调整 | 先以效果图选型；用户选原版锁屏，因此 A/B/C 试验排版均未合入。D1 不强制设置面板高度。 |
| 暂缓 | reapply、自动更新 PR、非 NixOS 分发、SDDM、Plymouth、新图标和 Issue 模板。 |
| 不采用 | 缺少锁屏资源时自动跳过；继续报错并保证零写入，保留显式 `--skip lockscreen`。 |
