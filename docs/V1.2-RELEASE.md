# v1.2.0 发布依据

目标版本：1.2.0。以已在 NixOS generation 55 通过核心实机验收的开发提交 `9438a155a5b4b80dc53d9bdd555bf641bedb6e2f` 为依据。
正式构建更新六处版本标识与发布资料；控制器逻辑、D1 SVG、锁屏 QML、壁纸、配色、指针及图标不作新的调整。

## 相比 v1.1 的变化

- 原版锁屏保持原有布局、文字、原生模糊和认证；继续不叠加亮度处理或遮罩。
- D1 桌面精修：面板 / 弹窗 / 提示框圆角 8 / 10 / 6，阴影不透明度 0.12，保留用户面板配置。
- 只读版本诊断核对构建资源与当前 Plasma 会话；证据缺失为 unknown，版本相同不等于任意构建都兼容。
- 保留 INI 换行；无后改的非 GTK 配置按原始字节恢复，有后改仍按键恢复，GTK 保留非主题键。
- 中英文使用、恢复与卸载文档，带来源哈希的缩略图，以及独立的每周锁定依赖 / unstable 检查。

## 已验收依据

- 开发源码 84 项单元测试通过；锁定 nixpkgs `da6dc0e7b26060f2f71ce3ef7088fb56ee44fa36` / Plasma 6.6.6 构建和 flake check 通过。
- unstable `d357a2b54f0b6dc4aeb4e993190a52cf151b6f24` / Plasma 6.8.2 构建通过；没有在其 GUI 会话做实机解锁验收。
- 3120×2080 / 175% RHI 软件 OpenGL、1920×1080 / 100% Qt 软件后端完整隔离回归通过，保留十四张原始截图。
- 真实内屏验收：用户确认锁屏亮度、文字、密码解锁、D1 桌面/菜单观感和鼠标点击正常；布局、字体、缩放和指针尺寸保持。
- 自动监测捕获锁定，未在五分钟内捕获解锁信号。人工确认与之后的已解锁状态单独记录，未把监测超时标成自动通过。

最小公开验收数据见 [v1.2-acceptance.json](v1.2-acceptance.json)；[截图来源](../previews/v1.2/manifest.json)保留开发源码身份。
正式构建、源码包与 SHA256SUMS 单独生成并校验；托管 CI 以对应提交的 Actions 结果为准，不将旧提交的结果冒充当前结果。

## 升级与范围

从 v1.1 或此前仍报告 1.1.0 的 D1 开发包升级，先用当前工具 restore，再安装 1.2.0 并 apply。
请与系统使用同一套 pkgs 构建，随 Plasma 升级重建主题；细节见 [升级与恢复](UPGRADE-RECOVERY.md)。
外接多屏、五档指针逐档实屏测试、真实虚拟键盘输入与 TTY 故障演练未完成。当前内屏核心验收通过不扩展为这些项目的通过。
源码包不包含个人配置恢复记录或真实桌面文件；素材署名、GPL 派生 QML 与其他权利范围见 [CREDITS](../CREDITS.md)。
