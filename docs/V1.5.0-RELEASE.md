# v1.5.0 发布候选依据

日期为 2026-11-08。此本地候选以 `508b1fff58b8bd894c4c495e879dbb0ee5c8711a` 为发布基线，整合功能定稿 `e27bc6114a8866fe7fce51af8138bbc03d26aab1`。基础主题、动态壁纸、SDDM、控制器和发行元数据统一使用 1.5.0。

## 本版内容

- 选择医疗白绿锁屏壁纸后，待机时左上方显示时间和日期。唤醒时，首字母头像和密码框出现在同一列，继续使用 Plasma 的认证流程。
- 注销、重启和关机确认页在左栏显示时钟、倒计时与操作按钮。窗口和桌面面板由主题自带锁屏壁纸覆盖，画面保留原亮度。
- SDDM 底部按钮获得键盘焦点时，显示一深一浅两道不透明边框。此变化同时适用于正常布局和错误提示布局。

使用自定义锁屏壁纸时，确认页仍显示主题自带壁纸。这项限制适用于三个会话操作。

## 验收依据

以下为功能定稿及其父提交的记录。不同运行环境各自判定。

| 环境 | 项目和结果 |
|---|---|
| 隔离 Qt 离屏 | 定稿的确认页在四组尺寸下共执行 24 项检查，20 项通过。Esc、取消按钮和空白点击发出取消信号的检查在四组均通过。四个失败均来自旧断言，它要求带颜色属性的全屏元素数为零，而当前壁纸容器铺满全屏。 |
| 虚拟机，SDDM | 3120×2080、175% 下，正常与错误布局的八张焦点原图均达到相邻壁纸 3:1 的门槛，双线之间最低为 12.9167:1。关机按钮在两种布局中的最低值分别为 3.6157:1、3.5991:1。[焦点取样说明](SDDM.md) |
| 虚拟机，确认页 | 在倒计时 29 秒比较空桌面与五种最大化窗口，逐帧最大差异为 7 个像素，最大通道差为 2。取消按钮的焦点框最低为 3.2424:1。一次空白点击后，10 秒内仍能看到确认页，保护性 Esc 成功关闭页面并回到原会话。 |
| 虚拟机，锁屏 | 在父提交与定稿的全新虚拟机中，错误提示出现后 +0.5 秒和 +1.5 秒的无掩膜全帧对照分别为 20 px／8、13 px／8，均达到 100 px／8 的门槛。+3.0 秒时一边已恢复输入，另一边仍显示错误，相差 18,187 px，最大通道差 213。两台虚拟机随后均成功解锁并返回各自原会话。 |

## 安装与升级

从候选源码目录运行 `nix build --no-write-lock-file path:.#kaltsit-theme` 构建基础包。`kaltsit-motion` 和 `kaltsit-sddm` 分别构建与安装，SDDM 需显式启用。系统模块使用调用方的 `pkgs`。基础主题的旧恢复记录应在升级前使用原版本恢复。[安装说明](../README.md) · [恢复指南](UPGRADE-RECOVERY.md) · [SDDM](SDDM.md) · [动态壁纸](MOTION.md)

源码包名称为 `kaltsit-medical-green-1.5.0.tar.gz`。素材作者、来源与许可列于 [CREDITS](../CREDITS.md) 和 [许可目录](../LICENSES/)。
