# Theme asset provenance

The Kaltsit Medical Green palette, folder SVG path data, configuration files,
and metadata created for this theme are original content, licensed under MIT.
They use standard KDE, freedesktop.org and Ghostty configuration formats.

The icon theme inherits `breeze,hicolor`; Breeze icons are resolved from the
installed system theme and are not copied into this package. Breeze widgets,
Plasma style and KWin decoration are runtime dependencies supplied by KDE.

Format references:
- Installed KDE Breeze 6.6.6: `share/color-schemes/BreezeLight.colors` and
  `share/plasma/look-and-feel/org.kde.breeze.desktop/contents/defaults`.
- https://develop.kde.org/docs/plasma/ and https://specifications.freedesktop.org/icon-theme-spec/latest/
- https://github.com/KDE/konsole/blob/master/data/color-schemes/Breeze.colorscheme
- https://github.com/KDE/konsole/blob/master/src/profile/Profile.cpp
- Installed Ghostty theme examples: `share/ghostty/themes/Adwaita`.

The wallpaper and cursor have separate provenance and usage rights recorded
by the asset import. The MIT license above does not relicense those assets.
