# v1.1 正式版准备

当前候选：**1.1.0-rc.2**，2026-11-01（Asia/Shanghai）。

rc.1 已部署至 NixOS generation 52，真实锁定/解锁通过，日常鼠标点击正常；
用户随后反馈密码输入页太亮、几乎全白，因此观感验收未通过。

rc.2 将锁屏调整为深色 Complementary、白字与深绿背景，让原生密码页压暗背景。
壁纸插件加入深绿薄衬底与顶部、底部渐变；桌面其他浅色组、原始 JPEG 和原生认证组件保持。
3120×2080 / 175% 的 RHI 原生隔离会话及恢复、回滚检查已通过，七张主组截图已重拍。
宽屏软件后端与 68 项测试、Nix 构建及 flake check 已通过。打包时实屏确认尚待进行，后续部署记录另行保存。

## 正式发布前的实屏验收

1. 部署 rc.2 后，在日常 175% 屏幕确认密码页已消除过曝，待机时钟、输入框和底部文字清楚，并完成一次正常锁定/解锁。
2. 保留 rc.1 日常鼠标点击正常的用户反馈；五档尺寸仍需逐档实屏确认。若使用外接显示器，检查热插拔和跨屏表现。
3. 确认当前素材组合与版本内容后，将候选版本更新为 `1.1.0`，生成正式附件并发布。
