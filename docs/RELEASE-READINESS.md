# v1.1 正式版准备

当前候选：**1.1.0-rc.3**，2026-11-01（Asia/Shanghai）。

rc.1 已部署至 NixOS generation 52，真实锁定/解锁通过，日常鼠标点击正常；
用户随后反馈密码输入页太亮、几乎全白，因此观感验收未通过。

rc.2 的压暗与深绿遮罩又被用户认为偏暗，用户明确要求取消亮度修改。
rc.3 因此移除全部壁纸遮罩，并仅对本主题将原生 Fader 的亮度、对比度与饱和度系数固定为 1。
原始 JPEG 字节以及原生模糊、认证、输入和焦点逻辑保留。Complementary 恢复浅底深字，本主题 Fader 仍保持中性。

rc.3 通过 Nix 构建生成局部 KDE QML 差异，并在构建时原样复制匹配依赖的完整 shell。
完整资源层会参与 shell 包发现；必须使用与系统相同的 `pkgs`，随 Plasma 升级重建，避免旧资源遮盖新版本。
上游替换片段有精确匹配检查，生成的派生 QML 保留 GPL-2.0-or-later 许可。

## rc.3 验证与交付

- 69 项自动检查、离线 Nix 构建和 flake check 通过；生成资源预检和上游精确片段检查通过。非主题分支与上游代码逐字节对照一致，未另做实时 A/B。
- RHI 与软件后端完整隔离会话通过；已重拍十张原图并刷新预览清单。待机和密码页取消所有遮罩和调色，使用深色时钟。
- 待实机部署：使用与系统匹配的包检查完整 shell 的资源发现、应用、重复应用、恢复及正常锁定/解锁。
- 待分支推送后执行 rc.3 托管 CI。
- 完成用户观感确认后，整理源码发行包、SHA256SUMS 与对应版本的验收结果。

rc.1 / rc.2 的 68 项测试、已有构建及独立会话结果保留作历史回归依据；rc.3 的通过范围以上述本轮结果为准。
rc.3 自动测试、构建和原生隔离预览已通过；实机结果和用户观感将在部署记录中更新。

对应结果和运行方式见 [验收记录](VALIDATION.md)，图像原件及哈希见 [预览](../previews/README.md)。

## 正式发布前的实屏验收

1. 部署 rc.3 后，在日常 175% 屏幕确认壁纸不再额外提亮或压暗，原生模糊、时钟、输入框及底部文字正常，并完成一次正常锁定/解锁。
2. 保留 rc.1 日常鼠标点击正常的用户反馈；五档尺寸仍需逐档实屏确认。若使用外接显示器，检查热插拔和跨屏表现。
3. 确认当前素材组合与版本内容后，将候选版本更新为 `1.1.0`，生成正式附件并发布。
